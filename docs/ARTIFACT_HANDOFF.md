# Передача осциллограмм и coverage внешним анализаторам (#6)

[English](ARTIFACT_HANDOFF.en.md)

Этот модуль **не анализирует сигналы** и не запускает внешние программы. Он предоставляет read-only MCP-инструмент `list_approved_artifacts(project_id)`, возвращающий манифест только тех файлов, которые оператор заранее перечислил в локальном разрешённом профиле. Ни пути файлов, ни команды от MCP-клиента не принимаются.

## Пример разрешённого профиля

Дополните существующий профиль (с обязательными `workspace`, `executable`, `do_script`, `do_sha256` и флагами согласия):

```json
{
  "artifacts": [
    {"id": "tb_vcd", "path": "waves/tb.vcd", "format": "vcd",
     "declared_time_unit": "ns"},
    {"id": "tb_fst", "path": "waves/tb.fst", "format": "fst"},
    {"id": "tb_wlf", "path": "waves/tb.wlf", "format": "wlf"},
    {"id": "coverage", "path": "reports/coverage.ucdb", "format": "ucdb"}
  ],
  "expose_artifact_paths": false
}
```

Не более 8 записей. Идентификаторы — короткие безопасные имена; относительные пути — с разделителем `/`, без `..`, символов `\`, `:` и символьных ссылок. Указанная метка `declared_time_unit` может быть `fs/ps/ns/us/ms/s`, **не считывается из осциллограммы и не проверяется**. Наличие файла не доказывает, что его создал только что завершившийся запуск. Поэтому всегда `origin=EXISTING_WORKSPACE_FILE_NOT_ATTESTED` и `produced_by_run_id=null`.

По умолчанию MCP **не возвращает абсолютный путь**. Только оператор может включить `expose_artifact_paths=true` в локальном манифесте, что позволяет доверенному локальному агенту передать путь внешнему инструменту. Не включайте это для неутверждённых облачных агентов, если файлы содержат закрытые сведения. Ответ никогда не включает содержимое файла.

## Результаты и ограничения

- Для обычных файлов размером до 8 МиБ вычисляется SHA-256 и размер; для больших — только размер со статусом `HASH_SKIPPED_LARGE_FILE`. Это не означает ошибку анализатора или подтверждённое происхождение.
- Для отсутствующих файлов, небезопасных ссылок, недоступных объектов или изменений во время чтения возвращаются отдельные состояния. Обход каталогов и переход за разрешённый корень блокируются в рамках возможностей переносимой реализации. Это не полноценная песочница от пользователя с такими же правами ОС.
- `format_validated=false` и `external_execution=NOT_RUN` всегда: расширение файла и хеш не доказывают корректность формата или успешный запуск анализатора.
- VCD/FST: маршрут к [Wavepeek](https://github.com/kleverhq/wavepeek) и опциональному [Tencent wave-mcp](https://github.com/Tencent/wave-mcp) отмечается как **возможный**, но не исполненный.
- WLF: `NOT_SUPPORTED_DIRECTLY` в Wavepeek/wave-mcp. В старых ModelSim имеется внешняя команда `wlf2vcd` для ручной конвертации после закрытия симуляции; этот сервер её **не запускает** и не гарантирует наличие в текущей редакции Siemens.
- UCDB: проприетарная база coverage; возвращается маршрут `VENDOR_UCDB_EXTERNAL_ONLY`, без собственного чтения показателей покрытия.

## Проверки

В публичном CI используются искусственные маленькие VCD и файлы-заглушки FST/WLF/UCDB. Проверяется **только манифест**: ограничения путей и размера, SHA-256, отсутствие утечек путей, типизация и реальный MCP tools/call. Заглушки **не** считаются валидными FST или WLF. Реальный Wavepeek/wave-mcp, конвертация WLF, анализ coverage и лицензируемая Questa: **NOT_RUN**.

Референсы: [Wavepeek](https://github.com/kleverhq/wavepeek), [wave-mcp](https://github.com/Tencent/wave-mcp), [ModelSim Command Reference, wlf2vcd](https://ww1.microchip.com/downloads/aemdocuments/documents/fpga/ProductDocuments/ReleaseNotes/modelsim_me_v105c_ref.pdf).

## Отдельный сбор свежих артефактов

Приведённые выше `origin=EXISTING_WORKSPACE_FILE_NOT_ATTESTED` и `produced_by_run_id=null` относятся к read-only инструменту `list_approved_artifacts(project_id)`. Для **наблюдения файлов конкретного запуска** реализована отдельная опциональная функция внутри `run_approved_project`, см. [run-scoped артефакты](RUN_SCOPED_ARTIFACTS.md). Она не повышает наблюдение до подтверждения авторства либо PASS.
