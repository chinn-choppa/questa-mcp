# Проверка проекта

[English](TESTING.en.md)

## Быстрые проверки без EDA и внешней сети

```bash
PYTHONPATH=src python -m unittest discover -s tests -v
python -m compileall -q src tests
```

PowerShell:

```powershell
$env:PYTHONPATH = "src"
python -m unittest discover -s tests -v
python -m compileall -q src tests
Remove-Item Env:PYTHONPATH
```

## При наличии SDK MCP

```bash
uv sync
uv run questa-mcp
```

Подключить MCP Inspector либо клиент Codex/Claude/OpenCode, проверить реальный `tools/list`, затем вызвать `server_info` и `parse_diagnostics` на синтетических данных. Только после успешного фактического вызова инструмента можно фиксировать `MCP_TOOL_PASS`. Простой старт процесса или наличие пакета означает максимум `INSTALLED`.

## Реальное EDA-тестирование

**Пока не предусмотрено** в bootstrap. После появления команд выполняйте на публичных минимальных RTL-проектах: lint, негативный кейс, сбой лицензии/тайм-аут, успешное завершение по самопроверяющемуся тесту, повреждённый файл, неверный путь и ограничение каталогов. Записывайте версии и SHA используемых исходников.

## Выполненная приёмка #2/#3

CI запускает настоящий клиент MCP через `stdio` и внутри процесса, проверяет `tools/list`, `tools/call` и отклонение некорректной схемы. Первый успешный запуск: [GitHub Actions 42054703978](https://github.com/chinn-choppa/questa-mcp/actions/runs/42054703978): Linux/Windows с Python 3.11 и 3.13, 4/4. SDK: `mcp==2.3.0`. Запуск Siemens Questa, лицензии, настоящая RTL-верификация, Python 3.15: **NOT_RUN**.

## Проверки макетного исполнителя (#4)

CI дополнительно проверяет запрет неподтверждённых проектов, несовпадение хеша DO, выход за корень/символьные ссылки, отсутствие shell, имитацию запуска, timeout, лимит вывода, fatal и ошибку лицензии в тексте. Это только mock-процессы, **не реальная Questa**.

## Фазовая модель верификации (#5)

Инструменты `assess_verification_run(record)` и `assess_regression(runs)` разделяют компиляцию, элаборацию, симуляцию, проверки и регрессии. Положительные заявления клиента **не повышаются до PASS**. См. [контракт верификации](VERIFICATION.md). Реальный Siemens EDA: **NOT_RUN**.

## Интеграционные mock-тесты JUnit (#5)

Добавлены проверки XML с ограничениями размера, запретом DTD, несогласованными счётчиками, повторами/пропусками имён и skipped; нового пути на каждый запуск; закрепления хеша бинарника до/после; повреждённого UTF-8, чрезмерно длинных строк журнала, ошибок и отсутствующих отчётов. Настоящий MCP-клиент вызывает `tools/list`/`tools/call` с **макетом** процесса Siemens. Положительная фикстура даёт `checker_verdict=PASS`, но `test_verdict=UNKNOWN`. Коммерческий Siemens и лицензия в CI не используются. См. [контракт JUnit](JUNIT_EVIDENCE.md).

Регрессионные тесты безопасности #4 дополнительно проверяют отмену **во время создания процесса** и повторную отмену, пока очистка ещё не завершена. Временный снимок DO не должен удаляться до завершения операции очистки. Это mock-процессы; завершение потомков реального Siemens на Windows/Linux остаётся NOT_RUN.

## Манифесты VCD/FST/WLF/UCDB (#6)

Синтетическая фикстура VCD и заглушки FST/WLF/UCDB проверяют только metadata/routes. Тесты контролируют границы workspace, symlink, неверные расширения, запрещённые пути, недостающие файлы, SHA-256 малых файлов, отсутствие чтения больших файлов и сокрытие локальных путей. Настоящий MCP-клиент проверяет `tools/list`/`tools/call` нового инструмента. Фактическое открытие FST в Wavepeek, преобразование WLF, обработка UCDB и работа коммерческой Questa: `NOT_RUN`.

## Регрессия по утверждённым фазам (#5)

Unit/mock и настоящий in-process MCP тестируют порядок трёх фаз, разные seed, остановку при ошибках compile/elaboration, отсутствие ложного PASS, запрет повторов/неверных типов seed, подмену бинарника и отклонение отсутствующего профиля. Пофазные процессы замещены синтетическими mock-реализациями. Реальная коммерческая Questa — `NOT_RUN`. См. [фазы](PHASE_RUNNER.md).

## Тесты каталога конкретного запуска

Синтетические процессы проверяют два различных seed и run_id, переменную `QUESTA_MCP_ARTIFACT_DIR`, SHA-256, сокрытие путей, отказ при неверном корне и symlink, а также настоящий MCP `tools/call` на исполнение и повторное чтение. Коммерческий EDA не требуется.
